# 浅間山 · Кольцо Куробу

Сайт-презентация однодневного маршрута по Асаме (22.09):
車坂峠 → сомма Куробу → Jバンド → 湯の平 → 前掛山 → 草すべり → 車坂峠.
~18,6 км, набор ~1560 м, максимум 2524 м.

Скролл привязан к ходу дня: свет на 3D-рельефе, положение солнца, туман
и маркер на профиле высот меняются вместе с таймингом выхода.

## Файлы

| Путь | Что это |
|---|---|
| `index.html` | исходник для Claude Artifacts (без `<head>`, его добавляет платформа) |
| `site/index.html` | самостоятельная страница для деплоя — то, что отдаёт Vercel |
| `build.py` | собирает `site/index.html` из `index.html` |

После правки `index.html` выполнить `python3 build.py`.

## Стек

Three.js r128 (рельеф, небо, маршрут), инлайновый SVG для профиля высот,
без сборщика. Один файл, никаких зависимостей кроме CDN.
